# Project conventions

- **Single branch policy:** work directly on `main` unless there's a specific
  reason to branch (e.g. a risky experiment). Don't leave stray feature
  branches around after merging — delete them.
- **No "claude" in branch names.** If a branch is ever needed, name it after
  what it does (e.g. `add-size-filter`), not by tool/session.
